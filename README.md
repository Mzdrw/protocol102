Протокол-102: Заметки для совещаний

Веб-приложение для создания и управления заметками во время планерок и совещаний. Разработано в рамках производственной практики (Кейс-задача №4) для МБОУ «Гимназия №102».

Посмотреть в работе: https://mzdrw.github.io/protocol102/

Основные возможности
- Создание, редактирование и удаление заметок с указанием даты, времени, категории и автора.
- Удобный поиск по ключевым словам, тегам или датам.
- Два режима хранения данных: локальная база SQLite (в браузере) или сохранение в обычные файлы (.json / .md).
- Адаптивный дизайн: удобно работает и на компьютере, и на телефоне.

Инструкция для проверки (для научного руководителя)

Чтобы протестировать приложение, не нужно ничего устанавливать или настраивать. 

1. **Запуск:** Просто откройте файл "index.html" в любом браузере (Chrome, Яндекс.Браузер, Edge) или перейдите по ссылке выше.
2. **Создание записи:** Нажмите кнопку **«+ Новая заметка»**. Заполните заголовок, дату и текст. Нажмите «Сохранить» (или комбинацию Ctrl+S). Заметка сразу появится в общем списке.
3. **Поиск:** Введите любое слово из текста заметки в строку поиска сверху, чтобы проверить работу фильтрации.
4. **Проверка хранения:** Нажмите на значок меню **☰** в правом верхнем углу. Там можно переключить режим хранения с «SQLite» на «Файлы», а также скачать все заметки одним файлом для резервной копии.
5. **Мобильная версия:** Если сузить окно браузера или открыть ссылку с телефона, интерфейс автоматически перестроится и будет выглядеть как обычное мобильное приложение.

*Полное руководство пользователя с пошаговыми скриншотами всех функций уже добавлено в текст отчета по практике*
